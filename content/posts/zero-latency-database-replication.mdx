High availability distributed databases must balance consistency, availability, and partition tolerance (the CAP Theorem).

In active-active multi-region deployments, Conflict-Free Replicated Data Types (CRDTs) allow writes to proceed concurrently on all nodes without blocking network roundtrips.

## Consensus Algorithms: Raft vs Multi-Paxos

Leader-based replication ensures strong consistency, but introduces round-trip latency when writes originate far from the leader node.

<Callout type="danger" title="Split-Brain Prevention">
Always maintain an odd number of voting nodes in Raft clusters to prevent split-brain quorums during network partitions.
</Callout>

## Go CRDT LWW-Element-Set Implementation

```go filename="db/crdt_lww.go"
package db

import (
	"sync"
	"time"
)

type Element struct {
	Value     string
	Timestamp int64
}

type LWWRegister struct {
	mu      sync.RWMutex
	current Element
}

func NewLWWRegister(initialVal string) *LWWRegister {
	return &LWWRegister{
		current: Element{
			Value:     initialVal,
			Timestamp: time.Now().UnixNano(),
		},
	}
}

func (r *LWWRegister) Update(val string, ts int64) bool {
	r.mu.Lock()
	defer r.mu.Unlock()

	if ts > r.current.Timestamp {
		r.current = Element{Value: val, Timestamp: ts}
		return true
	}
	return false
}
```
