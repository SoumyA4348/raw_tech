The central cloud model is undergoing a massive transformation. Edge computing places processing nodes within physical proximity to end-user requests, cutting latency down to single-digit milliseconds.

## Why Edge Runtimes Outperform Legacy Cloud VMs

Legacy server instances incur high cold-start costs and geographic routing overheads. Edge runtimes leverage lightweight V8 isolates or WebAssembly (WASM) modules to instantiate execution contexts in under 5 milliseconds.

<Callout type="warning" title="WASM Memory Boundaries">
WebAssembly modules run within isolated linear memory spaces. Ensure memory allocation limits are configured before routing heavy traffic payloads.
</Callout>

```javascript filename="workers/edge-handler.js"
export default {
  async fetch(request, env, ctx) {
    const startTime = performance.now();
    const url = new URL(request.url);

    // Cache-Control header strategy for static pre-rendered SSG assets
    const response = await fetch(request);
    const newHeaders = new Headers(response.headers);
    newHeaders.set('X-Edge-Latency', `${Math.round(performance.now() - startTime)}ms`);

    return new Response(response.body, {
      status: response.status,
      headers: newHeaders,
    });
  },
};
```
